# Assets Folder

This folder contains all the media files for the portfolio website.

## Required Images

### Profile Image
- **File**: `profile.jpg`
- **Size**: 400x400px (square)
- **Format**: JPG or PNG
- **Description**: Professional headshot or avatar
- **Important**: Save your profile image as `profile.jpg` in this folder to replace the default placeholder

### How to Add Your Profile Image:
1. Save your professional photo as `profile.jpg`
2. Place it in the `assets/` folder
3. The image should be square (1:1 ratio) for best results
4. Recommended size: 400x400px or larger
5. The website will automatically use your image

### Project Screenshots (Optional)
Add screenshots for your projects to enhance the visual appeal:

- `nexus-video-call.jpg` - Screenshot of the video calling app
- `wanderlust.jpg` - Travel booking platform screenshot  
- `weather-now.jpg` - Weather app interface
- `mini-chat.jpg` - Chat application screenshot
- `snake-game.jpg` - Snake game screenshot
- `currency-converter.jpg` - Currency converter interface

## Image Guidelines

- **Format**: JPG or PNG (WebP for better performance)
- **Size**: Optimize for web (under 500KB each)
- **Dimensions**: 
  - Profile photo: 400x400px (1:1 ratio)
  - Project screenshots: 800x600px (4:3 ratio) or 1200x800px
- **Quality**: High quality but web-optimized

## Optimization Tips

1. Use tools like TinyPNG or ImageOptim to compress images
2. Consider WebP format for better compression and performance
3. Use appropriate alt text for accessibility
4. The website includes lazy loading for better performance

## Fallback

If no profile image is provided, the website will show a default avatar placeholder automatically.

The portfolio now features a custom cursor with:
