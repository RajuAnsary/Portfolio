# Raju Ansary — Portfolio

Personal portfolio featuring full-stack applications, AI projects, and data analysis work.

## Website

Static HTML, CSS, and JavaScript. Serve the project folder with a local static HTTP server and open `index.html`.

The current page uses `modern.css`, `personal.css`, `modern.js`, `personal.js`, and `theme.js`. Project information is also recorded in `projects.json`; project artwork and photos are in `assets/`.

Includes responsive project cards, category filters, a light/dark theme, animated background, and contact links. The contact form opens an email draft; it does not send messages through a backend.

Earlier styling files are retained for reference. Local preview screenshots and machine-specific browser checks are excluded from Git.
